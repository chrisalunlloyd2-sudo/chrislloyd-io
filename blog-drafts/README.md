# blog-drafts

Working dir for blog candidates. The queue lives in backlog.json (topic + season +
target page; 1 candidate drafted per month by the blackboard worker).

Promotion is OWNER-APPROVED ONLY: nothing here is ever published automatically.
On approval, run the verbatim command in the matching PROMOTE-*.txt sidecar
(one `python3 scripts/add_post.py` call; see PROMOTE-interior-vs-exterior-winters.txt).
